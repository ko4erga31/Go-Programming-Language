# learning-go

My solutions to the exercises from **The Go Programming Language** by A. Donovan & B. Kernighan.

## Structure

``` go
go.mod
ch01/
  ex1.1/main.go     one folder per exercise (one main per package)
  ex1.2/main.go
```

## Run

```sh
go run ./ch01/ex1.1 hello world
```
